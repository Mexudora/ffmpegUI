# ffmpegUI

Графический интерфейс для FFmpeg на Qt 6.9.3 и QML.

**Версия:** 0.1.0-alpha.1 · **Платформа пакета:** Windows x64.

## Возможности

- Просмотр сведений о медиафайлах и дорожках.
- Добавление файлов и папок в набор для обработки.
- Выбор дорожек и общих параметров их конвертации: MP4/MKV,
  H.264 или копирование видео, AAC с выбором битрейта или копирование аудио.
- Последовательная очередь с добавлением заданий во время выполнения.
- Просмотр команды FFmpeg, прогресса и журнала, отмена текущего задания.

## Требования

- Windows x64 и среда выполнения Microsoft Visual C++ v14 x64,
  совместимая с используемым MSVC 2022.
- Отдельно установленный FFmpeg с `ffmpeg.exe` и `ffprobe.exe` в одной папке.

**FFmpeg в архив не включён.** Доступные кодеки зависят от установленной сборки.
Установка Qt на компьютере пользователя не требуется: зависимости Qt входят в пакет.

## Первый запуск

1. Распакуйте **весь** архив в отдельную папку и запустите `ffmpegui.exe`.
2. Откройте «Настройки» и укажите папку с `ffmpeg.exe` и `ffprobe.exe`,
   например `C:\ffmpeg\bin`. Нажмите «Сохранить».
3. Откройте файл для просмотра или добавьте файлы/папку в набор обработки.
4. Выберите дорожки, параметры и выходной путь, добавьте задания в очередь.
5. Запустите очередь.

Путь к FFmpeg сохраняется в пользовательских настройках Windows.
Не переносите `ffmpegui.exe` отдельно от остальных файлов пакета.

## Ограничения альфа-версии

- Очередь хранится в памяти и не восстанавливается после закрытия приложения.
- Существующие выходные файлы не перезаписываются.
- После отмены может остаться незавершённый выходной файл.
- Изображения субтитров не преобразуются в текст через OCR.
- Дорожки без названий сопоставляются по типу, языку и порядку появления;
  проверяйте соответствие дорожек между файлами.

Для первых проверок используйте копии медиафайлов.

## Разработка и выпуск

C++17, Qt **6.9.3**, CMake **3.21+**, Ninja, MSVC 2022 x64.
Скопируйте `CMakeUserPresets.json.example` в `CMakeUserPresets.json`
и задайте свой путь к Qt. Локальный файл не включается в Git.
Если он уже существует, добавьте нужные пресеты вручную, сохранив свои настройки.

Из окружения MSVC x64:

```powershell
cmake --preset local-debug
cmake --build --preset local-debug
```
